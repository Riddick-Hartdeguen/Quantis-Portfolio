# Roadmap

Quantis évolue par étapes, d'une application qui fonctionne entièrement dans le navigateur vers une application full stack.

## V1 : gestion locale du budget (version actuelle)

- Saisie du salaire, des charges fixes et des opérations du mois.
- Calcul des revenus, des dépenses, du solde disponible et du budget consommé.
- Sauvegarde des données dans le navigateur avec `localStorage`.
- Interface responsive.
- À venir : consultation des différents mois.

## V2 : interface React

- Réécriture de l'interface avec React.
- Organisation de l'application en composants réutilisables.

## V3 : API et base de données

- Création d'une API avec Node.js et Express.
- Stockage des données dans une base MongoDB.

## V4 : comptes utilisateurs

- Inscription et connexion.
- Sécurisation de l'accès aux données personnelles.

## Versions suivantes

- Catégories plus détaillées et personnalisables.
- Graphiques et visualisations du budget.
- Continuité d'un mois à l'autre : le salaire, les charges fixes et le solde du mois précédent sont reportés automatiquement sur le mois suivant.
